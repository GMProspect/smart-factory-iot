## 📖 About the Project
A hybrid Edge-to-Cloud architecture that integrates real-time computer vision and predictive maintenance for modern manufacturing. This project enables high-speed sorting and anomaly detection directly on the factory floor while syncing analytics to the cloud.

## ✨ Key Features
- 🌐 **Digital Twin**: Real-time 3D Digital Twin rendering for remote monitoring and control.\n- 🧠 **Edge AI**: Local artificial intelligence for predictive maintenance and early anomaly detection.\n- ☁️ **Cloud Telemetry**: Seamless cloud telemetry integration for enterprise-level operational reporting.
