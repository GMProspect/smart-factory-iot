# Industrial IoT Smart Sorting System (Prototype)
> *Integración real IT/OT: Visión Artificial en la Frontera (Edge) para Industria 4.0.*



En la manufactura moderna, la latencia entre la detección de un defecto y la actuación mecánica es crítica. Los sistemas tradicionales de visión suelen ser costosos y rígidos. Se buscaba demostrar una arquitectura flexible y de bajo costo capaz de clasificación a alta velocidad e integración con ERPs.

## 💡 La Solución
Un prototipo de **Smart Factory** que implementa una arquitectura Híbrida Edge-Cloud. El sistema clasifica productos en tiempo real usando visión artificial local y reporta telemetría a un backend centralizado para analítica de negocio.

### Características Clave
- ✅ **Visión en el Edge**: Procesamiento local de imágenes para clasificación inmediata (sin latencia de nube).
- ✅ **Osciloscopio IoT Integrado**: Monitoreo en vivo de la señal de corriente de los motores para detección de fallas.
- ✅ **Fuente de Potencia Regulable**: Diseño electrónico propio para alimentación estable del sistema de control.
- ✅ **Integración API BCV**: Conexión en tiempo real con el Banco Central de Venezuela para ajuste de costos operativos según tasa cambiaria.
- ✅ **Dashboard HMI**: Interfaz web reactiva para monitoreo de planta en modo Kiosco.

### Tecnologías Utilizadas
| Categoría | Tecnologías |
|-----------|-------------|
| **Edge Compute** | Raspberry Pi / Python (OpenCV/TensorFlow Lite) |
| **Control** | Arduino / C++ (Actuación Mecánica) |
| **Backend/ERP** | Node.js / Python |
| **Protocolos** | MQTT / REST / Serial |

## 🚀 Impacto
- **Validación Tecnológica**: Demostración funcional de clasificación automática de bajo costo.
- **Trazabilidad Total**: Registro digital de cada unidad procesada para control de calidad.
